# LeoCare PWA

A mobile-friendly pet-care planner prefilled with Leo's known details (Labrador Retriever, male, 34 kg), all editable.

Features: pet profile; vaccination, grooming and doctor appointment schedules; last-done and next-due dates; repeat intervals; reminder lead times; mark-as-done care history; custom schedule items; user checklist; CSV export; JSON backup/restore; Apple Calendar (.ics) reminder export; offline app shell.

## Install on iPhone
Upload every file in this folder to the root of an HTTPS static website. Open its URL in Safari on iPhone > Share > Add to Home Screen.

## Reminders and storage
Data is stored in local browser storage on this device. No automatic iCloud/server sync or scheduled background push notifications are configured. Use Download backup regularly. Export the .ics file and open/import it into Apple Calendar; verify event dates and alert settings after import.

Use vaccine and appointment intervals provided by Leo's veterinarian. This app is a record keeper, not veterinary advice.
